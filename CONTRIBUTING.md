# Contributing to WebhookHub

Thank you for contributing to WebhookHub.

## Before opening a pull request

1. Keep the change focused and follow the existing project style.
2. Add or update tests when behavior changes.
3. Run `go test ./...`.
4. Disclose copied or adapted third-party material and its license in the pull
   request.

## Contributor License Agreement

Every contributor must accept the [Individual Contributor License
Agreement](CLA.md) before a pull request can be merged. Add this exact statement
to the pull request description or a pull request comment, replacing the two
placeholders with your details:

> I have read and agree to the WebhookHub Individual Contributor License
> Agreement v1.0. I am contributing as FULL LEGAL NAME using GitHub account
> @USERNAME.

Post the statement from the same GitHub account that submits the contribution.
The pull request and its comments are retained as the record of acceptance.
The maintainer will verify the statement manually before merging.

Do not use the individual agreement if an employer or another person or
organization owns the contribution and has not authorized you to submit it.
Ask the rights holder for written authorization or contact
[ivan.parfenov.42a@gmail.com](mailto:ivan.parfenov.42a@gmail.com) to arrange a
separate organization agreement.

Submitting a contribution does not guarantee that it will be accepted.
